# Основная игра: анимации, оружие и арена

Новая система работает внутри мастерской и боевой арены основной игры. Motion Lab остаётся отдельным инструментом разработки. Старый формат сохранений, роботы, коллекция, корм, золото, яйца, достижения и прежний прогресс поддерживаются.

## Запуск

- Windows: распаковать `build/windows-motion-v23/Clicker-Windows.zip` целиком и запустить `Clicker/Clicker.exe`. Папка `_internal` нужна рядом с EXE. Используется установленный в Windows WebView2; Flutter, Python и сервер игры уже упакованы. Интернет для анимаций не нужен.
- Из исходников Windows: `run_game_windows.cmd` или `uv run python src/main.py`. Клиент собирается командой `uv run python tools/build_windows_game.py --build-number 24`.
- Android: `build/apk-game-v22/clicker.apk`. Это тестовая сборка с тестовыми рекламными блоками Google, без рекламного дохода. Подпись совместима с прежним APK v16; сохранения при обычном обновлении сохраняются. Не удалять старую игру перед установкой обновления.
- Сборка следующего APK: `uv run python tools/build_main_game_apk.py --build-number 23`.

Старый AAB v17 относится к прежней версии игры. Новый APK не является AAB для загрузки в Google Play.

## Что изменилось

Восемь роботов используют один редактируемый Rive-риг с индивидуальными формами, подвижными узлами, скоростью, походкой и способностями. Есть гусеничные, шагающие и парящие роботы. Голова, корпус, предплечья, кисти, глаза, брови, колёса, гусеницы, шестерни и декоративные элементы двигаются независимо. Движение колёс и гусениц вычисляется по пройденному расстоянию. В мастерской робот патрулирует, моргает, реагирует на кормление, осматривается; приближение, перетаскивание и сброс камеры доступны в увеличенной мастерской.

Десять типов оружия: плазма, снайперская винтовка, ракеты, лазер, электрическая пушка, пулемёт, энергетический меч, щит, огнемёт и дрон. В разделе «Роботы → Арсенал» доступны покупка, десять уровней улучшений и установка двух видов оружия. Установленное оружие меняет внешний вид и реальные характеристики атаки. Оружие чередуется, расходует энергию, имеет собственные эффекты и звуки. Старые способности роботов сохранены.

Бои включают подготовку, выстрел или сближение, полёт атаки, попадание, отбрасывание, ответ и восстановление. Есть щит, уклонение, зарядка, эмоции, искры, дым, вспышки, волны энергии и тряска камеры. Урон применяется один раз при завершении фазы атаки. Анимации не изменяют инвентарь самостоятельно.

Добавлены уровни сложности ботов, новые арены, способности боссов, кубок ботов, недельные задания, редкие детали и дополнительные достижения. Сетевые бои и кланы выделены в подразделы арены.

## Сетевые бои и кланы

Сервер находится в `server/`. Инструкции: [server/README.md](server/README.md). Он поддерживает очередь настоящих игроков, рейтинговые пошаговые бои, рейтинг, награды, создание и вступление в кланы, развитие, общие задания, войны и получение наград. Это работающая реализация с локальной HTTP-проверкой двух клиентов; публичный сервер в этой сессии не развёрнут.

Без указанного сервера PvP и кланы показывают состояние отсутствия подключения. Ботов игра явно называет ботами. В рейтинговых боях характеристики нормализованы, результаты и рейтинг вычисляет сервер. Сетевая валюта отделена от старого локального золота, поэтому клиент не может отправить своё сохранение как доказательство победы или баланса.

## Проверки и ограничения

- Регрессии Python: 198 тестов, включая старые сохранения, награды, однократные ходы, отмену задач и реальные HTTP-запросы двух тестовых клиентов.
- Flutter: прошли 80 проверок игровых сцен и 5 проверок движения; проверяются реальные элементы Flet, загрузка опубликованного Rive-рига и отсутствие переполнений в портретных и горизонтальных сценах, в том числе 320 × 640.
- Замер основной игры в Windows/Chrome, Flutter profile, 2382 × 1648, 20 окон после прогрева: старая версия — медиана 120 FPS, минимум скользящего окна 89,25 FPS; новая — медиана 120 FPS, минимум 115,91 FPS. Максимальные p95 UI/raster новой версии: 6,70/2,50 мс. Это разные по сложности реализации боя; цифры не означают ускорение каждой операции.
- Замер Chrome не является измерением готового Windows EXE или телефона. Стабильные 60 FPS на Android ещё нужно подтвердить на устройствах; проверка телефона отложена по просьбе владельца.
- Rive-файл экспортирован официальным CLI с сохранением заставки бесплатного плана. Исходник: `animation/rive/game_robot/scene.rml`; повторный экспорт: `uv run python tools/prepare_game_animation.py`.
- Звуки созданы в проекте и хранятся в `src/assets`; звук можно отключить кнопкой в сцене. Системная настройка уменьшения движения поддерживается.

Windows сохраняет данные в `%APPDATA%/Clicker/data`. Тестовые запуски используют отдельные каталоги и не открывают реальное сохранение. Android использует приватное хранилище приложения. Ключи подписи не включаются в дистрибутив.

Полный отчёт проверок: [build/game-verification-v23/summary.json](build/game-verification-v23/summary.json). В архиве Windows проверены байткод 16 основных модулей и 102 файла ресурсов. В APK сверены 31 модуль, 15 звуков, опубликованный Rive-файл и три архитектуры; 128 библиотек для 64-битных архитектур прошли проверку выравнивания на 16 КБ. Подпись APK совпадает с v16. Импорт модулей из самого APK дополнительно проверен CPython 3.14.7 на компьютере.
