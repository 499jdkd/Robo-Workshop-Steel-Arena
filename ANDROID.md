# Android: зависимости и проверка

Для первой тестовой загрузки в Google Play подготовлена отдельная подписанная
сборка AAB17: `build/play-test-v17/clicker.aab`. Инструкция по тестовому треку,
подписи и сохранению прогресса: [GOOGLE_PLAY_TESTING.md](GOOGLE_PLAY_TESTING.md).
Сборка использует тестовые рекламные блоки Google; основной APK16 остаётся
с рабочими ID. Следующая тестовая сборка: `build_google_play.cmd 18`.

Для запуска игры на компьютере откройте `run_game.cmd` или выполните
`uv run python src\main.py` из каталога `C:\Clicker`.
Этот запуск использует окружение проекта с `flet-ads`.
Обычная команда `python` вне активированной `.venv` может выбрать системный
Python без зависимостей игры.

В старом `build/apk/clicker.apk` упакован `leaderboard.py` с `import aiohttp`.
Текущий исходный код использует `httpx`. Установка пакета на компьютере не
добавляет его в уже собранный APK: Flet берёт зависимости из `pyproject.toml`.

В проекте явно указан `httpx==0.28.1`. Flet и инструменты разработки закреплены
на версии `1.0.4`, которая была установлена для запуска приложения на компьютере.
При проверочной сборке эта версия выбрала Flutter `3.44.8` и JDK 17.

Для сборки из CMD или PowerShell в каталоге проекта:

```cmd
.\build_android.cmd 16
```

Число — номер сборки. В версии `16` исправлена передача событий наградного
видео; предыдущая `15` добавила коллекцию, сцены и инкубатор. Для следующего
обновления укажите `17`, затем `18`.
Скрипт синхронизирует окружение проекта, выбирает Flutter нужной Flet версии,
использует установленный JDK 17 и включает UTF-8 только для этого запуска.
Готовый APK: `build/apk-fixed/clicker.apk`.

В исходники добавлен баннер AdMob с ID владельца приложения Robot warrior.
О настройках аккаунта и проверке типа блока см. [ADS.md](ADS.md).
Прежние сборки с тестовой рекламой сохранены отдельно.

Новая версия игры № 16: `build/apk-rewarded-v16/clicker.apk`. Для установки на телефон
или пересылки через Telegram нужен именно файл `.apk`.
Рекламный блок в APK № 10 подтверждён как партнёрский: он не подходит для прямых
запросов AdMob. В APK № 11 блок `…/6629980699` также оказался партнёрским по
подтверждению пользователя; на телефоне он возвращает HTTP 403. Для показа рекламы
в APK № 12 он заменён на Banner_2 `…/1108034582`, подтверждённый в разделе
«Стандартный». Пользователь подтвердил показ баннера на телефоне после APK № 12.
В APK № 13 убрана подпись над баннером и уменьшен отступ. Эта настройка и рабочий
блок Banner_2 сохранены в APK №15, включая горизонтальные сцены.
Предыдущий APK №14 сохранён в `build/apk-motion-v14/clicker.apk`.
Предыдущий APK №15 сохранён в `build/apk-expansion-v15/clicker.apk`.
APK №13 сохранён в `build/apk-admob-v13/clicker.apk`. APK № 12 сохранён в
`build/apk-admob-v12/clicker.apk`. Обновление объявлений и учёт дохода описаны в
[ADS.md](ADS.md). Прежний APK № 9 содержит тестовую рекламу Google.
Кормление и бои: [ARENA.md](ARENA.md). Коллекция и графика: [ROBOTS.md](ROBOTS.md).
Версия № 9 с тестовым баннером сохранена в `build/apk-ad-recovery/clicker.apk`,
версия № 8 — в `build/apk-arena/clicker.apk`, версия № 7 — в
`build/apk-robots/clicker.apk`, версия № 6 — отдельно
в `build/apk-workshop/clicker.apk`. Базовые механики: [WORKSHOP.md](WORKSHOP.md).

Отдельный запуск регрессионных тестов:

```powershell
uv sync
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

После смены Flutter старый кеш в `build/flutter/.dart_tool` может вызывать
`Invalid kernel binary format version`. В восстановленной сборке кеш Flutter
`3.41.7` заменён кешем `3.44.8`. Предыдущий кеш и готовый APK сохранены в
резервных каталогах внутри `build`.

Тесты используют подставные HTTP-ответы и не отправляют запросы в базу игроков.
Они проверяют загрузку и отправку прогресса, отсутствие сети, ответы сервера с
ошибкой, сортировку лидеров, сохранение device_id, офлайн-доход и создание экранов
настоящим Python-рендерером установленного Flet. Для сборки №15 дополнительно
проверяются портретные и горизонтальные экраны через Flutter с сохранением PNG;
они используют
искусственные профили и макет места баннера. Проверку запуска APK, поворота
экрана и настоящего баннера на Android нужно выполнить отдельно.

Рейтинг читает сервер независимо от загрузки сохранения. Код серверного
восстановления и пошаговая настройка Atlas/Render: [Microservice/README.md](Microservice/README.md).
Этот код подготовлен локально; внешний сервер пока не развёрнут заново.
После Resume кластера Cluster0 владельцем 14.11.2026 действующий сервер
восстановился: HTTP 200, пять записей рейтинга. Проверка настоящим клиентом
игры прошла без изменения прогресса. Для этого пересобирать APK не нужно.

Чтобы сохранить device_id и связь с существующим прогрессом, устанавливайте
обновление поверх приложения с тем же package ID и той же подписью. Удаление
приложения или очистка его данных удаляет локально сохранённый идентификатор.
