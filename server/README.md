# Сервер сетевой арены Clicker

FastAPI + транзакционный SQLite/WAL. Сервер не создаёт фиктивных игроков и не подменяет отсутствующих соперников ботами. Офлайн-бои основной игры работают отдельно.

## Локальная проверка

Из `C:\Clicker`:

```powershell
$env:CLICKER_ARENA_DB = 'C:\Clicker\.cache\arena-local\arena.sqlite3'
uv run uvicorn server.app:app --host 127.0.0.1 --port 8000 --workers 1
```

В основной игре открыть «Арена → Игроки», указать `http://127.0.0.1:8000` и имя. Для второго клиента требуется отдельное приватное хранилище. Два тестовых HTTP-клиента также проверяются командой `uv run python -m unittest discover -s tests -p test_online_http.py -v`.

`GET /health` сообщает протокол 1 и `opponents: human-only`. `/docs` содержит схему API. Клиенту возвращается случайный токен; на сервере хранится только его SHA-256. Токен нельзя публиковать. Смена сервера создаёт отдельную сетевую личность, старое локальное сохранение остаётся прежним.

## Бой и рейтинг

Очередь соединяет двух различных зарегистрированных игроков. Характеристики нормализованы для честного тестового PvP, робот и оружие дают различные способности. Сервер рассчитывает урон, энергию, кулдауны, победу, валюту и изменение рейтинга. Ход ограничен 45 секундами; выход из боя и истечение срока приводят к поражению. Ревизия состояния и уникальный ID команды защищают от повторного применения запроса. Переданные клиентом урон и баланс не принимаются.

Основные маршруты: `POST /register`, `GET /me`, `POST/DELETE /queue`, `GET /match/current`, `POST /match/{id}/turn`, `GET /ranking`.

Кланы: `GET /clans`, `POST /clans/action`. Есть создание, вступление, выход с передачей владельца, пожертвования, уровни, недельная общая цель, награды за личный вклад и войны с подсчётом реальных рейтинговых побед над участниками другого клана. Бои с ботами в клановый рейтинг не попадают. Награды защищены от повторного получения.

## Развёртывание

Подготовлен `server/Dockerfile`. Он запускает один процесс на порту 8000. Для небольшого тестирования нужен постоянный диск, смонтированный в `/data`; `CLICKER_ARENA_DB=/data/arena.sqlite3`. Доступ игрокам следует предоставлять через HTTPS. В игре можно указать публичный HTTPS-адрес без пересборки APK. Локальный HTTP разрешён для проверки на компьютере; Android должен подключаться к HTTPS.

Не запускать несколько экземпляров с разными SQLite-файлами: у них будут разные очереди, рейтинги и кланы. Для нескольких реплик нужно перенести транзакции в общую PostgreSQL-базу, добавить распределённую очередь/уведомления и тестирование конкурентных операций. Перед публичным масштабированием также нужны ограничение частоты запросов на шлюзе, резервное копирование, восстановление учётных записей, наблюдение за ошибками и нагрузочная проверка. Сейчас это небольшой сервер для тестирования, а не проверенная инфраструктура массового мультиплеера.

Публичное развёртывание, доступ к Render и настройка домена в этой сессии не выполнялись. Старый сервис MongoDB для прежнего списка кликов и новый сервер рейтинговых боёв — отдельные компоненты; адрес старого сервиса не подходит для нового протокола.
